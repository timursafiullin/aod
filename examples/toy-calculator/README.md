# toy-calculator

A tiny project for trying the AOD delegation loop; the [quick start](https://github.com/timursafiullin/aod/blob/master/docs/quick-start.md) walks through it. Copy it somewhere outside this repository, `git init`, commit,
open Claude Code there and run `/aod:init`. Then ask the architect for a first task, e.g.
"Create a task for Codex: implement `src/calc.mjs` exporting `evaluate(expr)` for + - * / with integer
operands and precedence; throw `SyntaxError` on malformed input."
